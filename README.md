This is a small program that writes one short text — a single line for make.fun's bounty `u-gudril-cool-one-line-best-line-b8c41f4d`, where entrants write one free and entertaining line of at most 240 characters — into the folder named by `MAKEFUN_OUTPUT_DIR` when it is set and `/output` otherwise, creating that folder and printing the character count to stderr.

```text
The waiting-room fish has a name tag on his bowl: Gerald. Gerald has been dead since Tuesday. The tag is new.
```

Run it with `MAKEFUN_OUTPUT_DIR=out python3 main.py`; the written file is `entry.txt`, exactly the text above with no trailing newline.
